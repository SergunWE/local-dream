# План русской локализации Local Dream

## Результаты просмотра проекта

- Android-приложение на Kotlin и Jetpack Compose, версия в конфигурации — 2.8.1. Минимальная версия Android — 9 (API 28).
- Основной набор текстов: `app/src/main/res/values/strings.xml`, 395 строковых ресурсов и 10 ресурсов множественного числа.
- Существующие переводы: `values-zh`, `values-ja`, `values-ko`. Количество строк и ресурсов множественного числа совпадает с основным набором. Русского перевода пока нет.
- Большая часть интерфейса использует `stringResource`, `pluralStringResource` и `getString`. Новый язык можно добавить через стандартные Android-ресурсы.
- Собственного переключателя языка и декларации `android:localeConfig` в просмотренном коде нет. Языковое разделение App Bundle отключено.
- Обнаружены тексты непосредственно в Kotlin: экран рисования, выбранные файлы при импорте моделей, отдельные сообщения и подписи иконок. В сервисах есть английские названия/описания каналов уведомлений и текст прогресса генерации.
- В истории используется фиксированный шаблон даты `MM/dd HH:mm`; время генерации и размеры файлов местами форматируются с `Locale.US` и английскими обозначениями единиц.
- Используется системный шрифт `FontFamily.Default`. Отдельный шрифт для русского языка по результатам просмотра не требуется; отображение кириллицы нужно проверить на устройстве.
- Пути к Android SDK настроены, команды Java и adb доступны. Сборка и запуск в рамках этого просмотра не выполнялись.

## Предлагаемый объём

Полный русский интерфейс приложения: модели и их описания, настройки, генерация и её параметры, история и фильтры, рисование, обрезка, дорисовка, увеличение разрешения, UltraFix, импорт моделей/LoRA/эмбеддингов, резервное копирование, связь устройств, уведомления и подписи для экранного диктора.

Сохранить название Local Dream, имена моделей, Stable Diffusion, SDXL, Anima, UltraFix, LoRA, CLIP, CFG, CPU/GPU/NPU и названия алгоритмов. Переводить пояснения к ним. Значения промптов, теги, идентификаторы, JSON-ключи, сетевые протоколы и форматы обмена параметрами сохранять совместимыми. Словарь русских переводов тегов — отдельная функция и отдельный объём работ.

## Этапы

1. **Уточнить поведение языка и терминологию.** По умолчанию предложен русский при русском системном языке, с английским базовым набором для остальных неподдерживаемых языков. Согласовать необходимость ручного выбора языка. Предлагаемые термины: «Промпт», «Негативный промпт», «Сид», «Дорисовка», «Увеличение разрешения»; дать понятные пояснения в подсказках.
2. **Подготовить ресурсы.** Создать `app/src/main/res/values-ru/strings.xml` и перевести весь основной набор. Сохранить имена ключей, типы и позиции подстановок (`%s`, `%1$d`, `%2$.1f`), экранирование, ссылки и переносы строк. Для 10 ресурсов множественного числа добавить формы `one`, `few`, `many`, `other` с корректной грамматикой.
3. **Перенести оставшиеся пользовательские тексты из кода.** Добавить недостающие ключи в базовые английские ресурсы и русские переводы. Повторно использовать существующие ключи для общих действий. Обновить экран рисования, импорт файлов, сообщения, каналы уведомлений, прогресс и подписи доступности. Проверить происхождение ошибок, показываемых через `e.message`: собственные сообщения локализовать, технические детали внешних библиотек и backend сохранять как диагностические подробности.
4. **Проверить форматирование.** Использовать подходящее для русского языка представление дат, длительности и единиц измерения в интерфейсе. Не менять машинные числовые форматы весов тегов, имена файлов резервных копий и сериализацию. Проверить обновление сохранённых в памяти описаний моделей после изменения языка, особенно при добавлении ручного переключателя.
5. **Проверить интерфейс.** Просмотреть основные экраны и диалоги на русском, включая длинные подсказки и названия кнопок, на узком экране и с увеличенным системным шрифтом. При необходимости исправить переносы и размеры элементов. Проверить подписи для TalkBack и отображение уведомлений.
6. **Выполнить техническую проверку и подготовить результат.** Сверить покрытие ключей, подстановки и формы множественного числа; проверить значения 1, 2, 5, 11, 21, 22, 25. Выполнить сборку ресурсов, Android Lint и debug-сборку; при изменениях Kotlin выполнить ktlint и detekt. Проверить сохранение английского интерфейса при английском языке и совместимость импорта/экспорта параметров. Для визуальной проверки потребуется доступное ARM64-устройство или подходящий эмулятор; запуск генерации отдельно зависит от совместимого оборудования и установленных моделей.

## Критерии готовности

- Все предназначенные для перевода базовые ресурсы имеют русский вариант.
- Пользовательские сообщения и подписи доступности в затронутых экранах и уведомлениях используют ресурсы.
- Подстановки безопасны; множественное число и даты отображаются корректно.
- Русские надписи читаемы, действия не скрываются из-за длины текста.
- Сборка и относящиеся к изменению проверки проходят; доступные сценарии запуска проверены, ограничения проверки указаны.

## Согласованные решения

1. В настройках есть выбор «Русский» / «English». При первом запуске язык выбирается по основному языку системы: русский для `ru`, английский для остальных. Затем сохраняется выбранный язык.
2. Оставлены термины «промпт», «сид», «эмбеддинг», названия моделей и алгоритмов.
3. Переведён только интерфейс. README не изменён. Китайский, японский и корейский переводы удалены; сборка ограничена английским и русским.

## Результат реализации и проверки

- Добавлены 468 русских строк и 10 наборов множественного числа; ключи и подстановки сверены с английскими.
- Добавлен переключатель языка с сохранением выбора: AndroidX AppCompat для активности, собственное хранение на Android 9–12 и системное хранение на Android 13+. Строки сервисов и репозиториев явно используют выбранный язык.
- Настройки сохраняют открытое состояние при пересоздании активности. Описания моделей обновляются; даты, длительность генерации и размеры файлов локализованы при отображении. Форматы истории и обмена параметрами сохранены.
- Собраны debug-варианты `basic` и `filter`; ktlint и Android Lint выполнены (Lint: 0 ошибок).
- На Android 14 прошли два теста русских ресурсов: формы множественного числа/подстановки и английский fallback для удалённых языков.
- Тест переключателя и пересоздания экрана пропущен из-за заблокированного телефона. По просьбе пользователя дальнейшая проверка выполняется без телефона; визуальная проверка и проверка на Android 9–12 остаются ограничениями.
- Detekt 1.23.7 не запускается с установленной Java 25, в том числе при явном `jvmTarget=17`; конфигурация проекта ради обхода этой несовместимости не изменена.
